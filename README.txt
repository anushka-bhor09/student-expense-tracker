# Student Expense Tracker 💰

## About the Project

This is my first Python project, which I created to practice the basics of programming.

As a student, I wanted to build something simple and useful, so I decided to create an Expense Tracker. It helps me record my expenses, view them, and calculate how much I have spent in total.

## Features

- Add a new expense with its name, category, and amount.
- View all the expenses I've added.
- Calculate the total amount spent.
- Handle invalid amount inputs.
- Use a simple menu to navigate through the program.

## Technologies Used

- Python

## What I Learned

While building this project, I got hands-on practice with Python concepts such as variables, lists, dictionaries, functions, loops, conditional statements, and error handling.

This project helped me understand how these concepts work together to create a small, working application.

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   ```bash
   python expense_tracker.py
   ```
